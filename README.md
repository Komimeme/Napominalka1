"Напоминалка"
Инструкция по запуску приложения «Напоминалка» в StackBlitz
1. **Открытие проекта.** Перейти на сайт [StackBlitz](https://stackblitz.com/) и открыть созданный проект приложения «Напоминалка» на React с использованием TypeScript и Vite.

2. **Установка зависимостей.** После открытия проекта StackBlitz автоматически устанавливает необходимые зависимости, указанные в файле `package.json`. Если установка не началась автоматически, необходимо открыть терминал и выполнить команду:

   ```bash
   npm install
   ```

3. **Запуск приложения.** В терминале выполнить команду:

   ```bash
   npm run dev
   ```

   Если сервер разработки ещё не запущен автоматически, после выполнения команды StackBlitz запустит приложение и отобразит окно предварительного просмотра.

4. **Просмотр приложения.** В окне Preview отобразится интерфейс приложения «Напоминалка», содержащий статистику задач, список задач и информацию о сроках их выполнения. При необходимости можно открыть предварительный просмотр в отдельной вкладке браузера.

5. **Проверка работоспособности.** Убедиться, что приложение отображается без ошибок, а данные задач выводятся корректно. Если изменения в коде сохранены, Vite обычно автоматически обновляет страницу.

6. **Повторный запуск.** При последующем открытии проекта StackBlitz может автоматически запустить приложение. Если предварительный просмотр не отображается, необходимо проверить терминал и при необходимости выполнить `npm run dev`.
